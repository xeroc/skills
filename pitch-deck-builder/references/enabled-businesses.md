# Enabled Business Categories (Platform Pitches)

For platform/protocol pitches where the product enables an ecosystem, list enabled business categories as proof of platform value — not as a roadmap.

## How to Frame

The line: "We're not building these businesses. The ecosystem is. We're the layer they all run on."

Each category = proof that the protocol is versatile enough to support many different businesses. Each business flows through the protocol and earns protocol fees.

## Using This in a Pitch

### In the slide (Proof Points)

Show 6-10 categories max as a clean grid. Pick the ones that resonate with your audience:

- Crypto-native angels → AI agents, stop-loss, limit orders
- Finance angels → treasury, yield, DCA
- Generalist angels → family banking, inheritance, giving

### In speaker notes

"Each composition is a new product. Each product flows through Tributary. Each flow earns protocol fees. We're not building all of these — the ecosystem is. We're the protocol underneath."

### If asked "which one are you focusing on?"

"None of them. We're the layer they all run on. The market picks the winners. We earn on every flow."

## Adaptation for Non-Tributary Pitches

For any platform/protocol pitch, build your own grid:

1. List every business type your technology enables
2. For each, write a one-line hook that a non-technical person understands
3. Include an "X for Y" analogy where possible (Patreon for crypto, Acorns on-chain)
4. Categorize by audience segment (B2B, B2C, B2B2C, machine-to-machine)
5. Show 6-10 in the deck, keep the full list in appendix

The grid proves platform value. The speaker note clarifies you're not building all of them.
